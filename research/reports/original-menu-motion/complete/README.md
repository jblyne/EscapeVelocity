# Original main-menu animation reference

Captured directly from the running original Escape Velocity in Infinite Mac (System 7.5.3), using 200 consecutive browser screenshots after returning from flight with Escape. Raw JPEGs and capture timestamps are retained. Timings include the keypress and browser capture overhead; they are visual reference timestamps, not exact game frame timings.

- `original-swing-stages.png`: six views of the top pair unfolding and resolving its lettering.
- `original-swing-slow.gif`: the captured sequence at approximately one-third speed.
- `contact-sheet.png`: wider sequence showing successive rows.

The original face opens from an edge-on pose. During the middle of the swing, its lower edge reaches farther inward toward the center of the menu than its upper edge. The mechanical hinge also changes orientation. Each pair finishes before the next begins. The vertical reflection introduced in local build 0.1.247 contradicts these captured silhouettes.
