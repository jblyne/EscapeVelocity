# EV 1.0.5 startup and story cues

Evidence: original local EV 1.0.5 PowerPC executable, read-only disassembly
(`/tmp/ev-ppc.txt`, regenerated by tools/disassemble_ev_reference.py), and
original EV Music / EV Titles resource forks. Addresses below are code-section
relative, not guessed wall-clock observations.

- Startup 0x15350 calls 0x4b784 (title music), then 0x15358 calls
  0x4abd0 (PICT 8100 publisher logo). Music starts before the logo routine.
- 0x4b7ec selects music resource 30000, Title Music.
- 0x153ac calls 0x4aa14, selecting PICT 131 at 0x4aa4c;
  the loading meter initializes at 0x153b4. Main menu setup 0x4c2fc selects
  PICT 8000. There is no story call between startup and the main menu.
- Enter Ship dispatch 0x4ccb8 calls 0x4eb58. That checks the intro-seen flag;
  a loaded pilot sets it at 0x285e8/0x293f4, and initial pilot setup clears it
  at 0x5d1c4. New pilots receive the introduction; existing loaded pilots skip it.
- Intro 0x4f7cc selects PICT 8200. 0x4f8c8 selects music 30003 Transition.
  0x4f958–0x4f960 waits up to 480 TickCount ticks (8 seconds), with input skip.
- 0x4f9cc starts 30001 Drum Intro via 0x4b900, which also loads 30002 Drum Loop
  and uses a completion callback. 0x4f9d8 passes STR# 20000 to the text scroller.
- Text renderer 0x4b0a8 clears to black, uses 30-pixel line spacing and advances
  one pixel per two ticks normally (0x4b6d4–0x4b6f0), about 30 pixels/second.

Implementation preserves original PCM bytes in all four music WAVs, carries
one title player across the scene switch, and separates the arrival-picture
cue from the black story scroll. Story coordinates scale from 640×480 to the
832×624 design canvas (factor 1.3). Source palette fades use 16-step routines;
modern alpha fades map these to a nominal 60 Hz. Actual loading duration is
hardware-dependent and cannot equal vintage wall-clock loading on every Mac.
The old artificial two-second publisher hold and pre-menu story were removed.
